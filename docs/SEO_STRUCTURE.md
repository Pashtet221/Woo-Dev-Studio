# SEO Structure

Status: draft. Final sitemap and keyword mapping must be validated before mass page production.

## Primary commercial sections

- `/` — Home
- `/services/` — Services overview
- `/woocommerce-development/` — WooCommerce development
- `/wordpress-development/` — WordPress development
- `/plugin-development/` — Custom plugin development
- `/theme-development/` — Custom theme development
- `/integrations/` — Integrations
- `/maintenance/` — Maintenance / ongoing development
- `/projects/` — Projects / case studies archive
- `/about/` — About
- `/contact/` — Contact
- `/blog/` — Insights / blog

## Content intent model

- Commercial intent -> Pages
- Proof / project evidence -> Case Studies
- Informational intent -> Posts

## Internal linking principles

- Service pages should link to relevant case studies.
- Case studies should link back to relevant services.
- Blog posts should support commercial pages where contextually relevant.
- Avoid orphan pages.
- Avoid near-duplicate landing pages targeting trivial keyword variants.

## Before production

For each planned landing page define:

- primary search intent
- primary topic / keyword cluster
- target audience
- page purpose
- supporting case studies
- supporting articles
- primary CTA

Do not create SEO pages purely because a keyword exists; the page must satisfy a distinct user intent.
